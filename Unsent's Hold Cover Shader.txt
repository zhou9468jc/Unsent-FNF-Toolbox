# Unsent's Hold Cover Shader

This package keeps the original Hold Cover atlas and XML metadata unchanged.

## Files

- `images/holdCoverRed.png` — original 599×591 atlas
- `images/holdCoverRed.xml` — original Sparrow atlas XML
- `shaders/holdCoverTint.frag` — runtime tint shader
- `scripts/holdCover.lua` — visual hold-cover controller

The shader converts the source atlas into a brightness mask at render time. The Lua script reads the current `playerStrums[*].rgbShader.r/g/b` values and sends them to the shader, so the Hold Cover follows the active arrow color.

## Placement

Put the files under the mod folder:

`mods/<YourMod>/images/holdCoverRed.png`
`mods/<YourMod>/images/holdCoverRed.xml`
`mods/<YourMod>/shaders/holdCoverTint.frag`
`mods/<YourMod>/scripts/holdCover.lua`

The script is intended for the Psych-compatible Lua API used by NFE. If your NFE build exposes a different player-strum property name, only `getStrumRGB()` needs adjustment.
