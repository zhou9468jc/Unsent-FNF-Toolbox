This is the folder for fonts. Two of the font files, "Lang-ZH.ttf" and "vcr.ttf", will replace the fonts in the game. If you don't want to replace the fonts, please rename or delete these two files.

Tip: If you want to use the old fonts, please delete Lang-ZH.ttf and vcr.ttf, then rename Lang-ZH.ttf.old and vcr.ttf.old to Lang-ZH.ttf and vcr.ttf, respectively.
